# The record

Five Fantasy Premier League calls a week. Written down before the deadline,
checked after the matches. The wrong ones stay up.

Published at https://fastpacedsnail.github.io/fpl-ledger/

Every commit in this repository is a timestamp. The calls for a gameweek are
committed before that gameweek's deadline, so the dates here can be checked
by anyone rather than taken on trust.

Not affiliated with or endorsed by the Premier League.
